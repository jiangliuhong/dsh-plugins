# dsh-chat-groups 第一版开发计划

目标：用户能在同一工作区内按任务整理会话，在左侧树切换会话，右侧始终使用 DSH 原生对话。[离线原型](prototype.html)记录了初版分组交互。首版已实现，并在 DSH Web `0.2.2-rc.5` 用真实 Bundle 验收。安装、停用及验收范围见[插件 README](../README.md)。

## M1：先验证侧栏能接管，也能还原

- 在工作区工具栏的「添加工作区」右侧提供「切换到会话分组视图」。默认不接管；选中后通过 `sidebar.workspaces` 注册替代列表，只展示当前用户可访问的工作区和会话。
- 通过 `ctx.uiWorkspace.openSession(id)` 打开已有会话，不嵌入聊天页。保留「返回默认视图」；返回或停用时撤销插件自己的注册，不禁用原生工作区插件。
- **通过条件**：在授权的测试环境往返切换，当前会话不被关闭；停用后原生列表、搜索快捷键和会话导航恢复。若插槽冲突或无法可靠恢复，先解决兼容性，不以操作 DOM 作为替代。

## M2：实现分组和会话操作

- 每个分组属于一个工作区，只填名称，不嵌套。支持新建、折叠、重命名，以及确认后删除。删除只清除组及成员关系，不删除、归档或关闭任何会话。
- 支持在组内新建会话，也支持将已有会话加入分组、移至同工作区其他组、移出到工作区直属列表。一个会话最多属于一个组；组内和直属列表不得重复出现。
- Host 持久化 `groupId → { workspaceId, name }` 和 `sessionId → groupId`。会话标题、访问权限、归档状态以 DSH 为准；Host 校验写操作的权限和工作区归属，不信任客户端传入的映射。删除组与清理成员关系应作为一次一致的更新。
- 在组内新建时以 `workspaceId` 创建原生会话，取得实际 ID 后保存归属。若会话已创建但保存归属失败，提示重试保存，不重复创建。

## M3：验收与发布准备

| 场景 | 通过条件 |
| --- | --- |
| 整理已有会话 | 在同工作区加入 A 组、移至 B 组、移出；每一步会话只出现一次，当前对话不变。 |
| 删除非空组 | 取消时无变化；确认后组消失，所有成员回到工作区且仍可打开。 |
| 权限与生命周期 | 拒绝跨工作区归组；不展示无权访问的会话，不绕过归档限制；会话失效时不留下可打开的假条目。 |
| 持久化与退出 | 重启后组名和成员关系不变；返回默认视图或停用插件后仍能使用原生列表。 |

先对分组数据规则做单元测试，再用真实 Bundle 重跑上表。记录实际验证的 DSH 版本、安装和停用步骤后，再将状态从「原型」更新为「可安装」。

**不在第一版范围内**：Worktree、Git、PR、目录绑定、拖拽排序、跨工作区移动，以及复刻原生搜索和归档界面。无需修改 DSH 源码。
