# dsh-chat-groups

在 DeepSeek Harness 工作区内按任务整理会话。分组只是会话的归属关系，不绑定目录。

## 原型体验

直接在浏览器打开[离线交互原型](docs/prototype.html)，无需安装依赖。

1. 在「客户端」工作区的 `⋯` 中选择「切换到会话分组视图」。左侧展示分组树，右侧会话不变。
2. 在「梳理启动流程」的 `⋯` 中选择「加入分组」，选择「登录改版」。已入组的会话也可以移动到同工作区的其他组，或「移出分组，返回工作区」。
3. 工作区旁的「＋ 新增分组」只需填写组名。组旁的「＋ 会话」新建模拟会话，`⋯` 支持重命名或删除分组。删除前会确认，组内会话会保留在原工作区。
4. 点击右侧示例可跨组或跨工作区打开会话。点「返回默认视图」可恢复默认列表，不关闭当前会话。

这是交互设计原型，不是可安装的 DSH Bundle。不连接 DSH，不执行 Git；刷新页面后恢复示例数据。
